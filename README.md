# IT Salary Dynamics in Germany: A Data-Driven Analysis

This project explores salary trends in the German IT industry based on survey data covering attributes such as experience, job role, company type, programming language, and more. It aims to provide actionable insights for tech professionals and employers about compensation patterns in different career contexts.

## Key Highlights

- **Median salary growth** observed from 2019 to 2020 across most IT roles.
- Average salary at entry level is ~€50K, scaling up to €110K for senior Data & Analytics roles.
- **Experience matters**, but plateaus after 20+ years for many non-technical roles.
- Programming language impacts salary: Go, Python, and TypeScript lead in compensation.
- Larger companies offer higher and more consistent salaries than startups.

## What’s Inside

- **Data Cleaning and Preparation**  
  Includes type casting, missing value treatment using medians, and standardizing categorical fields.

- **Salary Distribution Analysis**  
  Box plots and statistics comparing 2019 vs 2020 salary ranges by role and category.

- **Experience vs Salary Trends**  
  Detailed analysis of how total experience impacts earning potential across roles.

- **Factors Driving Salary**  
  Effects of main language spoken, programming language, company type, and size.
